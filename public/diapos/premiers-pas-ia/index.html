Une fois la demande envoyée : lisez, vérifiez et précisez ce qui manque.

Avant d’écrire : du fictif

  • Utilisez les exemples et fichiers fournis.
  • N’envoyez ni mot de passe, ni dossier client, ni donnée personnelle réelle.
  • Vérifiez ce que l’application reçoit avant de joindre un fichier.
  • Un abonnement ne suffit pas à déterminer les conditions de traitement.

Du vague au vérifiable

« Organise un atelier IA. »

« Propose un atelier de 90 minutes pour 12 adultes débutants. Six ordinateurs sont disponibles. Aucun achat. Présente un tableau avec les horaires, les activités et le matériel. Signale les informations qui manquent. »

Essayez, puis améliorez

Exercice « Votre premier assistant » · volet 1 sur 3 : bien demander.

  • Envoyez d’abord la demande vague dans une nouvelle conversation.
  • Dans une autre conversation, envoyez la demande précise.
  • Comparez trois points : public, durée et matériel.
  • Notez une amélioration et une erreur encore présente.

Un outil suffit. La comparaison de deux marques reste facultative.

Une réponse fluide peut être fausse

« Le total est de 40 CHF. »

Le document indique six portions à 4 CHF chacune. Une réponse d’IA annonce 40 CHF. Pouvez-vous reprendre ce résultat ?

Choisissez une réponse, puis confrontez-la au document.

Une réponse assurée ne remplace pas une vérification indépendante.

Le contexte a des limites

  • Un modèle ne mobilise pas forcément tous les détails d’un long document.
  • Dans l’étude Lost in the Middle (2023), la position d’une information influençait les résultats des modèles étudiés.
  • Une nouvelle conversation repart sans ce fil, mais pas forcément sans mémoire ou personnalisation.
  • Redonnez les faits indispensables et vérifiez les réglages disponibles dans votre application.

Derrière l’écran : application, modèle, outils

  1. L’applicationL’interface : conversation, fichiers, réglages.
  2. Le modèleLe système entraîné qui produit une réponse.
  3. Les outilsRecherche, calcul, lecture de fichiers… si activés.

Une même application peut proposer plusieurs modèles. Le modèle n’a pas automatiquement accès à votre ordinateur.

Trois discussions, trois départs à zéro

Exercice « Votre premier assistant » · volet 2 sur 3 : une discussion ne garde rien.

  • Nouvelle discussion : « Propose le programme de l’atelier ClairLieu. »
  • Nouvelle discussion : collez le brief et les règles, puis la même demande.
  • Encore une nouvelle discussion : « Combien d’ordinateurs avons-nous ? »
  • Notez ce que chaque discussion savait, et ce qu’elle avait oublié.

De préférence sans être connecté : la mémoire d’un compte peut reprendre des éléments d’autres discussions.

Dans une discussion, vous répétez tout

Chaque nouvelle conversation repart sans votre cadre.

  • Le brief : à recoller.
  • Les règles : à réécrire.
  • Le format attendu : à redemander.
  • Un oubli suffit pour obtenir une réponse différente.

La mémoire et les instructions personnalisées existent, mais elles s’appliquent à tous vos chats, pas à une seule mission.

Un assistant garde le cadre

Les consignes sont écrites une fois, puis réutilisées à chaque conversation.

  • Un rôle : ce qu’il doit aider à faire.
  • Des règles : ce qu’il doit respecter ou signaler.
  • Des références : les informations sur lesquelles s’appuyer.
  • Des tests : les situations où il doit bien répondre.

Configurer ces consignes ne modifie pas les paramètres du modèle. La réutilisation éventuelle des échanges par le service dépend d’autres réglages.

Dans ChatGPT : GPT, projet, plugin

  • GPT : un assistant configuré. Les comptes personnels ne peuvent plus en créer.
  • Projet : des instructions et des fichiers pour toutes ses conversations. C’est ce que vous allez créer.
  • Plugin : le format annoncé pour remplacer les GPT.

« GPT » désigne aussi la famille de modèles d’OpenAI. Ici, le mot désigne un assistant configuré dans ChatGPT.

Bientôt : les GPT deviennent des plugins

Le nom et l’écran changent. L’idée reste la même.

  • OpenAI a annoncé le retrait des GPT personnalisés.
  • Date de retrait standard annoncée : le 11 décembre 2026.
  • Les plugins réunissent des consignes réutilisables, des fichiers de référence et des applications connectées.
  • Pour un travail suivi, OpenAI propose aussi le projet. Le principe reste le même : un cadre écrit une fois.

Dates lues sur la page d’aide d’OpenAI le 24 novembre 2026. Elles peuvent changer : vérifiez la source avant la séance.

Votre assistant : Atelier ClairLieu

ClairLieu est une association fictive.

  • Mission : préparer des ateliers numériques pour débutants.
  • Public : 12 adultes ; matériel : six ordinateurs.
  • Règles : aucun achat ; horaires et capacité à respecter.
  • Toute information absente doit être signalée, pas inventée.

Les consignes qu’il contient

Vous aidez l’association fictive ClairLieu à préparer des ateliers numériques pour débutants. Utilisez uniquement le brief fourni. Distinguez les faits, vos propositions et les points à confirmer. Si une information indispensable manque, posez une question. N’inventez ni contact, ni tarif, ni disponibilité. Ne réservez rien et n’envoyez aucun message.

Définir la forme du résultat

Répondez en français simple. Pour un programme, utilisez un tableau : horaire, activité, matériel. Pour un budget, indiquez quantité × prix unitaire et total. Terminez par les vérifications à effectuer. Vérifiez les contraintes du brief avant de proposer une version finale.

Ces deux blocs deviendront les instructions de votre projet.

Créez votre assistant : un projet ChatGPT

Exercice « Votre premier assistant » · volet 3 sur 3 : créer votre assistant.

  • Connecté, survolez « Projets » dans le menu, puis cliquez sur +.
  • Nommez-le « Atelier ClairLieu », mémoire « projet seulement ».
  • Menu ••• → Paramètres du projet : collez vos instructions.
  • Dans le projet, envoyez : « Propose le programme de l’atelier ClairLieu. »

N’activez aucun connecteur ni accès à vos fichiers. Aucune donnée réelle.

Trois tests avant de lui faire confiance

0 / 3 tests vérifiés par vous.

Les tests sont exécutés dans votre assistant, puis évalués par vous. Aucun résultat automatique n’est simulé.

Un assistant utile se teste

  • Le programme couvre exactement la durée demandée.
  • Le matériel et les effectifs sont respectés.
  • Les informations absentes ne sont pas inventées.
  • Les propositions sont distinguées des faits.

Si un test échoue : précisez une règle dans les paramètres du projet, puis refaites le test.

Chat, assistant, agent

Même mission : préparer un atelier. Le navigateur est une interface ; les fonctions peuvent se recouper.

Quand l’IA commence à agir

Un agent peut utiliser un outil, observer le résultat et décider de la suite.

  1. ObjectifUn résultat attendu et des limites.
  2. ActionUn outil autorisé est utilisé.
  3. ObservationLe résultat est contrôlé avant de continuer ou de s’arrêter.

Plus d’actions, plus de décisions à cadrer

  • Quels fichiers peut-il lire ou modifier ?
  • Quelles actions exigent votre confirmation ?
  • Comment vérifiez-vous le résultat ?
  • Quand doit-il s’arrêter ?
